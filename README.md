# 📌 Project Overview

This project presents an **interactive Air Quality Analysis Dashboard** built using **Power BI** to analyze pollution data across India.

The dashboard helps users explore pollution trends by **State, City, Pollutant, and Time**, enabling better understanding of air quality patterns through interactive visualizations.

This project demonstrates the complete data analytics workflow:

- Data Collection
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Calculations
- Dashboard Design
- Insight Generation

---

# 🎯 Objectives

- Analyze air quality across India
- Compare pollution levels across states and cities
- Monitor pollution trends over time
- Identify the most polluted locations
- Build an interactive business intelligence dashboard

# 📂 Dataset

The project uses Air Quality Monitoring data from:

**Central Pollution Control Board (CPCB)**

Dataset includes:

- Air Quality Measurements
- Monitoring Stations
- States
- Cities
- Pollutants
- Date & Time
